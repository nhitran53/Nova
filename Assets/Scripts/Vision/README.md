# Vision

Ask NOVA **what am I looking at** or **what am I pointing at**
Unity captures the view and an optional close-up without the helmet HUD
Target names come from the scene
The Gemini key stays in Python

Point with a tracked hand then ask the question
Pointing alone does nothing
NOVA says when it cannot find a target
Desktop testing uses the centre of the view

Known wheel damage uses the demo reply and opens the assembly manual
Pinch the manual preview to open it
Drag one finger to scroll and use two fingers to zoom
Pinch the title bar to move it or press X to close
On desktop use L to open or close and Ctrl + mouse wheel to zoom

Press F7 in Play mode to save a local capture
The vision and manual components are added at runtime
Test pointing and page controls on Quest
